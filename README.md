# 伟大航路模拟器 · Grand Line Simulator V2

一个可直接运行的纯前端《伟大航路》冒险模拟器。

## 当前版本

- 船长属性：生命、攻击、防御、航海等级、悬赏金、贝里
- 伟大航路地图：10 个阶段岛屿与等级解锁
- 船员系统：路飞、索隆、娜美、山治、乌索普、罗宾
- 招募与船员切换
- 探索事件、随机遭遇战、普通攻击、技能攻击、撤退
- 经验与等级成长、奖励、悬赏金
- 航海日志
- 浏览器 LocalStorage 本地存档
- 移动端适配
- 无需后端，可直接部署 GitHub Pages

## 运行

直接打开 `index.html` 即可。

如果启用 GitHub Pages，可将部署来源设为 `main` 分支的根目录。
