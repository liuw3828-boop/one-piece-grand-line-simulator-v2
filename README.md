# 伟大航路模拟器 · Grand Line Simulator V2

一个可直接运行的纯前端《伟大航路》RPG 航海模拟器。

## 当前完整版系统

- 🗺️ 10 个阶段岛屿与等级解锁
- 👒 路飞、索隆、娜美、山治、乌索普、罗宾
- 👥 招募、切换出战伙伴
- ⚔️ 普攻、角色技能、霸气攻击、撤退
- ☠️ 多等级敌人、强敌与 Boss
- 📈 XP、等级、生命、攻击、防御、航海成长
- 💰 贝里经济与悬赏金
- 🚢 多艘船只、船只解锁与强化
- 🍖 恶魔果实系统
- 👁️ 三色霸气训练系统
- 🎒 装备系统
- 🔭 岛屿探索事件
- 🌊 海上随机事件
- 🏆 航海成就
- 📜 航海日志
- 💾 LocalStorage 自动存档
- 📱 移动端适配
- 🌐 无后端，可直接部署 GitHub Pages

## 已进入开发的长期 RPG 方向

- 📖 主线章节与岛屿剧情
- 💬 NPC 对话与分支选择
- ⚓ 海军、海贼、革命军等阵营关系
- 👑 强敌、Boss 与特殊战斗机制
- 🌳 角色技能树与羁绊
- 🧰 更完整的装备品质、强化与商店
- 🏴‍☠️ 船员编队与船只专属能力
- 🏁 多结局与最终岛屿剧情

## 运行

直接打开 `index.html` 即可。

GitHub Pages：将部署来源设置为 `main` 分支根目录即可。

## 项目定位

单文件、零后端、手机优先的 RPG。核心目标是先保证在浏览器中稳定运行，再逐步增加剧情、角色、Boss 与长期成长内容。
