# 伟大航路模拟器 · Grand Line Simulator V2

一个可直接运行的纯前端《伟大航路》RPG 航海模拟器。

## 完整版系统

- 🗺️ 10 个阶段岛屿与等级解锁
- 👒 路飞、索隆、娜美、山治、乌索普、罗宾
- 👥 招募、切换出战伙伴
- ⚔️ 普攻、角色技能、霸气攻击、撤退
- ☠️ 多等级敌人、强敌与 Boss
- 📈 XP、等级、生命、攻击、防御、航海成长
- 💰 贝里经济与悬赏金
- 🚢 多艘船只、船只解锁与强化
- 🍖 恶魔果实系统
- 👁️ 三色霸气训练系统
- 🎒 装备系统
- 🔭 岛屿探索事件
- 🌊 海上随机事件
- 🏆 航海成就
- 📜 航海日志
- 💾 LocalStorage 自动存档
- 📱 移动端适配
- 🌐 无后端，可直接部署 GitHub Pages

## 运行

直接打开 `index.html` 即可。

GitHub Pages：将部署来源设置为 `main` 分支根目录即可。

## 项目定位

这是一个单文件、零后端、手机优先的 RPG 原型完整版。后续可以继续扩展剧情章节、NPC 对话、更多角色、装备词条、技能树、Boss 机制、海军与四皇势力、排行榜和云端存档。
